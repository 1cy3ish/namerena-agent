# 共享知识

`overview.md` 保存入门概览；`glossary.json` 保存结构化术语；`sources.json` 保存引用来源。三者供 skill、agent、MCP 和后续检索服务共同使用。

## 来源

每条来源使用稳定的 `id`，记录页面标题、URL、类型、检索日期、读取状态和局限。`read_status: retrieved` 只表示本次读取了页面，不表示页面上的全部说法已经验证或仍然有效。初始来源以自行归纳与链接为主，不保存整站镜像。

## 术语

每个术语包含：

- `id`：稳定英文标识；`term`：常用名称；`aliases`：别名或缩写。
- `definition`：结合名字竞技场语境的简短解释。
- `category`：概念、玩法、输入规则或评分。
- `status`：`source_supported` 表示有来源支持这项释义；`unverified` 表示尚待核实。
- `scope`：来源语境和版本局限，不能省略为“适用于所有版本”。
- `source_ids`：指向来源目录的 ID；`checked_at`：核查日期。

有来源支持不等于当前社区已达成共识。遇到不同年代或群体的定义冲突，可新增独立词条并说明语境。问答中保留具体名字、战队名和输入字符，避免因改写而改变角色或对战条件。

待整理的原始材料可暂存于被 Git 忽略的 `data/raw/`；引用或收录前记录来源和使用授权。不要将私人聊天记录、凭据或未经授权的整站内容直接加入知识库。
