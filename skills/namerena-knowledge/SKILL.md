# 名字竞技场领域知识

此 skill 当前在 `namerena-agent` 仓库内使用，依赖同仓库的共享知识；独立分发时需要一并打包引用资料。

- 入门或规则问题：读取 [知识概览](../../knowledge/overview.md)。
- 黑话与缩写：按需检索 [术语表](../../knowledge/glossary.json) 中的 `term`、`aliases` 和 `scope`，将 pp、qp、pd、qd 等缩写按上下文匹配，避免在普通文本中无条件替换。
- 需要出处、日期或版本局限：通过 `source_ids` 查阅 [来源目录](../../knowledge/sources.json)，在回答中链接相应原始页面。
- 工具接入问题：从概览中的官方嵌入文档线索出发；iframe 示例不表示已有 HTTP 对战服务、模拟器或 MCP server。

## 容易误解的地方

- “号”在测号与对战语境中通常指名字及其角色。需要复现时保留完整输入，不能只使用战斗中显示的短名。
- `@战队名` 参与属性生成；空行划分本局队伍。两者不能互换。
- 评分、历史称号与最强榜单受版本、工具、样本和社区语境影响。Wiki 教程已声明部分内容停用，不直接采用其强度判断或旧阈值作为当前规则。
- 普通术语问题可直接解释；只有在版本或上下文会改变答案时才追问。未知黑话说明尚未收录，索取原句或来源，不按字面编造圈内含义。

用简体中文回答，先解释术语或结论，再补充必要的适用范围和来源。将文档记载、社区说法和实际验证的结果分开表述；当前知识库没有实测数据。
