# 名字竞技场领域知识

此 skill 当前在 `namerena-agent` 仓库内使用，依赖同仓库的共享知识；独立分发时需要一并打包引用资料。

- 入门或规则问题：读取 [知识概览](../../knowledge/overview.md)。
- 黑话与缩写：按需检索 [术语表](../../knowledge/glossary.json) 中的 `term`、`aliases` 和 `scope`，将 pp、qp、pd、qd 等缩写按上下文匹配，避免在普通文本中无条件替换。
- 需要出处、日期或版本局限：通过 `source_ids` 查阅 [来源目录](../../knowledge/sources.json)，在回答中链接相应原始页面。
- 属性、技能、特殊名字和语言包：从 [官方资料索引](../../knowledge/official/README.md) 按需读取结构化记录或页面快照。官方说明是基础来源，但列表可能不完整；语言包独有名称不能直接推导为完整机制。
- tswn、开箱器、评分、DIY/OL 或重写网页：先查 [tswn 知识入口](../../knowledge/tools/tswn-core/README.md)，具体评分见 `ratings.json`，普通技能 ID/短名见 `skill-map.json`，机制和网页各有专门说明。总表中的 `context_notes` 是有来源的实现补充，不能漏读后仍把附体、自爆、隐匿描述成仅有名称。
- 天梯、论坛、周赛、帮测或基地帖：读取 [社区知识入口](../../knowledge/community/ladder-forum/README.md)，必要时查观察摘要中的页面和帖子楼号；回答具体赛程、活动额度或领取条件时核对当届信息。
- 工具接入问题：从概览中的官方嵌入文档线索出发；iframe 示例不表示已有 HTTP 对战服务、模拟器或 MCP server。

## 容易误解的地方

- “号”在测号与对战语境中通常指名字及其角色。需要复现时保留完整输入，不能只使用战斗中显示的短名。
- `@战队名` 参与属性生成；空行划分本局队伍。两者不能互换。
- 当前无修饰的“天梯”默认指10007民间天梯，论坛在10008，游戏网页在10007的`/tswn/`。官方天梯通常加限定词；历史“老天梯”仍看原文链接。
- 天梯分数、QP注册验证和测号量不是同一个数值；成员活跃不直接证明周赛已激活。论坛基地帖也不同于Openbox base文件。论坛的“官方水楼”等主题名称不表示游戏官方运营。
- 版本按 [维护者约定](../../knowledge/project-context.json)：GitHub Pages 旧站过时，其余此前讨论的入口按最新版本处理。tswn 实现按已记录 commit 解释；其他工具与独立史料等待维护者提供，过时资料仍需收录。
- pp/pd/qp/qd 是 profile 万分制评分，cqd/cqp 是具体靶子集胜率，pair 可为头部加权和；rq 是构造参数，seed 是本场初始化材料。对有歧义的缩写先读相应 scope，不把数值或榜名混用。
- 评分、历史称号与最强榜单受版本、工具、样本和社区语境影响。保留来源页面的编辑提示，不因个别旧链接将整页归为旧版，也不把旧阈值作为当前定义。
- 普通术语问题可直接解释；只有在版本或上下文会改变答案时才追问。未知黑话说明尚未收录，索取原句或来源，不按字面编造圈内含义。

用简体中文回答，先解释术语或结论，再补充必要的适用范围和来源。将文档记载、社区说法和实际验证的结果分开表述；当前只有资源加载观察，没有可用于评分或胜率结论的实测数据。
