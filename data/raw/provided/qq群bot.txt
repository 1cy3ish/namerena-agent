小鱼bot：
📖 命令一览
群聊里要先 @ 我，或者用 /ladder- 前缀（例：/ladder-check）；随机 Say / 随机二创 不需要 @。

【绑定】
  bind <主队名>　申请把主队绑定到你这个 QQ（等主队在网站确认）
  unbind　解除当前 QQ 的绑定

【周赛激活】
  check [主队名]　查看主队和常驻战队的激活状态
  1 / 2 / …　check 之后回序号，激活对应的周赛组
  activate <战队> [组别]　激活战队，省略组别＝全部
  deactivate <战队> [组别]　取消激活（也可以 deactivate <序号>）
  activate-all　激活本主队及所有常驻战队的全部周赛组

【本周周赛】
  week / 周赛 [组别]　本周赛程与状态
  赛况 <组别> [战队名]　你这支队本周打到哪了：名次、是否淘汰、已打完的对手与胜负、下一场对手
  　　　　　　　　　　　（战队名不填＝你自己的主队）
  history / 历史 [组别] [数量]　最近几届冠军（默认 5）
  关注周赛　开关周赛提醒（开赛/你的比赛开始/你那局结果，在群里 @ 你）

【天梯】
  rank / 排行 [组别] [数量]　排行榜（指定组别默认前 10；不指定则每组前 3）
  查排名 [战队名]　该战队在各组别的名次（不填＝自己主队）
  战绩 <组别> [战队名]　该组别那个号的近期战绩（不填＝自己主队）

【名字评测（tswn-core / openbox-cli）】
  第一行发命令，第二行开始每行一个输入；群聊要先 @ 我或用 /ladder-
  pp / pd / qp / qd　单项评分（一行一个名字，或 + 连接多个）
  pf　一次算 pp/pd/qp/qd/合计
  cqp　100% CQP（一行一组，双人组用 + 连接）
  cp / fp / wcp / fsp / pjp　Openbox 队友评测
  peek / peeks　查看属性 / 技能（每行一个名字）
  todiy　导出 +ol DIY 文本（多人组用 ++ 分隔，例：a@t++b@t）
  base　原始 base 工具（一次一个名字）
  team / teams　同队加成后的属性 / 技能（一行一组，格式同 cqp；组间空行）
  namer　按网页格式打一场：空行分队，无空行即全体混战；输出胜者
  rate　测两队胜率：下面正好两行，每行格式同 cqp
  普通名字组用 + 连接；已导出的 +ol:/+diy[ 组用 ++ 分隔
  例：/ladder-pd　然后换行写 mario@team

【随机 Say】
  随机Say / say　直接抽一句
  随机Say 投稿 <一句话>　投稿（超过 100 字或多行会建议改投随机二创）
  随机Say 确认投稿 [内容]　被提示后强制投到随机 Say（10 分钟内；多行压成一行）
  @我 随便说点什么　不是指令的话，就抽一句回你（只 @ 一下也算）

【随机二创】
  随机二创 / erchuang　抽一篇二创（支持多行，最长 3000 字）
  随机二创 投稿 <内容>　投稿，后面可以换行写多行（超过 100 字的 Say 建议投这里）

【随机表情包】
  表情包 / 随机表情包　抽一个表情包
  表情包 投稿　开 1 分钟窗口，然后发一个表情包或图片过来（不用 @）

例：@我 check ／ /ladder-排行 1a 20 ／ 随机Say ／ 随机二创

namerena-v[0.10.4]
- /namer-help - 查看帮助
- /namerena - 运行名字竞技场, 每一行是一个输入, 输入格式与网页版相同
- /namer - 简化输入
- /namer-[pd|pd|qp|qd] - 你懂的评分
    - 一行一个名字/+连接的多个名字
- /namer-pf - 一下子全评
    - 一行一个名字/+连接的多个名字
- /namer-cqp /namer-cqd - 使用 tswn 计算 100% CQP, 一行一组，双人组用 + 连接
- /namer-cp /namer-bcp /namer-fp /namer-fzp /namer-wcp /namer-dp /namer-fsp /namer-pjp - Openbox 队友评测（bcp=cp，fzp=fp，dp=wcp）
    - 支持命令后直接输入或换行输入；A+B 评测与 B 组队加成后的 A
- /namer-peek - 查看一个名字的属性, 每一行一个名字
- /namer-peeks - 查看一个名字的属性, 技能按原始顺序输出
- /namer-base - base 工具, 只支持单个名字 (避免刷屏)
- /namer-team - 查看同队加成后的属性和熟练度, 每行一个名字
- /namer-teams - 查看同队加成后的属性和熟练度, 技能按原始顺序输出
- /namer-fight - 1v1 战斗, 格式是 "AAA+BBB+[seed]"
    - 例如: "AAA+BBB+seed:123@!" 表示 AAA 和 BBB 以 123@! 为种子进行战斗
    - 可以输入多行
